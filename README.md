# 키움증권 AI 기능 기획용 프로토타입

첨부된 `IMG_0581.PNG`의 국내잔고 화면을 재현한 모바일 웹 목업. 실제 증권 데이터, 로그인, 주문 API는 연결하지 않는다. 기존 ESB 제품 저장소와 분리된 독립 프로젝트다.

## 현재 범위

- 초기 화면: 국내잔고 / 키움 잔고 / 빈 보유종목 / 모든 잔고 0원
- 가상 계좌: `1234-5678 [위탁종합] 김철수`, `1234-0000 [종합매매] 김철수`
- 계좌 선택, 잔고 접기·펼치기, 새로고침 애니메이션과 알림
- 융자별·융자합, 1줄·2줄 표시, 정렬 선택, 화면 설정
- 미체결·예수금·주문가능금액·타사잔고의 간단한 시연 상태
- 메뉴·투자도구·유의사항·랭킹·해외잔고·일괄매도·지수채팅 시트
- 하단의 미구현 목적지는 안내 메시지로 반응한다. 지수 바 오른쪽 위의 원형 AI 버튼은 천사·고해소 컨셉의 고해성사 랜딩페이지로 이동한다. 뒤로가기를 누르면 기존 계좌 화면 상태로 돌아온다.
- 지수 수치는 모두 고정된 시연용 값이다. 매매, 자금 이동, 대화 전송이 발생하지 않는다.

React + TypeScript + Vite. iPhone / Pixel 10 선택, 터치·드래그 스크롤, 바텀시트는 모바일 프리뷰 런타임을 사용한다. GitHub Pages에서 공개 프로토타입을 제공한다.

## 다음 편집 위치

- `src/Prototype.tsx`: 초기 화면, 가상 상태, 버튼과 시트 동작
- `src/prototype.css`: 레이아웃·색상·글꼴·간격
- `public/assets/kiwoom/investment-tools.png`: 첨부 이미지에서 추출한 투자도구 아이콘
- `landingOpen` 화면 상태와 `openLanding` 함수가 진입 및 복귀를 담당한다. 새로운 기획이 확정되면 `ConfessionLanding` 컴포넌트의 내용을 편집한다. 원형 버튼은 지수 바 위 12px, 오른쪽 16px에 위치하며 앱 최상위 레이어(z-index 100)에 표시한다.
- `src/mobile/` 및 기타 보호된 런타임 파일은 `AGENTS.md` 지침에 따라 유지한다.

## 시각 재현과 한계

원본 1170×2532 이미지를 393×852 프리뷰 크기로 정규화해 비교했다. 레이아웃, 빈 잔고, 색상, 버튼, 하단 메뉴를 재현했다. 계좌번호와 이름은 사용자 요청에 따라 가상 정보로 교체했다.

원본 폰트 파일·앱의 서체 명세는 제공되지 않았다. Apple SD Gothic Neo와 시각 비교 후 더 가까운 **Noto Sans KR**을 로컬 패키지로 포함했다. 원본과 동일한 서체라는 보장은 없으며 일부 자폭·굵기와 작은 표준 아이콘은 미세하게 다를 수 있다. 아이콘은 Phosphor Icons를 사용하고 투자도구 아이콘만 원본에서 추출했다. 상태바의 시간·통신 표시, 기기 프레임, 홈 인디케이터는 프리뷰 런타임의 표시다.

## 기획 근거

- 사용자 최신 요청: 신규 키움 AI 기능 기획 → 웹 목업 제작 → 20~30초 광고 영상
- Notion: [2026-2 지산학캡스톤디자인](https://app.notion.com/p/3d6e47a1056080c49391c5edf1fe2efb)
- Notion 페이지는 맥락 확인을 위해 읽었으며 이번 작업에서 수정하지 않았다.
- [검증 기록](design-qa.md), 캡처는 로컬 `qa/`에 보관한다. 원본 비교 이미지와 QA 캡처는 공개 저장소 업로드에서 제외하며 앱에 노출하지 않는다.

AI 진입 버튼은 분홍빛 반투명 리퀴드 글라스 스타일이다. 배경 블러와 반사광, 얇은 하이라이트 및 은은한 그림자로 유리 질감을 표현한다. 사용자 제공 Tabler message-ai SVG가 항상 표시된다. Hover와 키보드 포커스 시 배경의 분홍·보라 틴트가 220ms 동안 더 진해지고, 터치 누름에는 더 어두운 색과 축소 피드백을 제공한다. 마스코트 전환은 제거했다. 동작 줄이기 설정에서는 색상이 즉시 전환된다.

AI 아이콘은 제공된 SVG의 viewBox와 경로를 그대로 유지하며 중앙 정렬한다. 버튼 가장자리는 1.5px 분홍·보라·하늘색 링이 4초에 한 바퀴 회전하며, 아이콘 자체는 회전하지 않는다. 동작 줄이기 설정에서는 링도 정지한다.


## 고해성사 랜딩 — 2026-10-02

- 선택 시안: `qa/landing-selected-reference.png`. 초기 시안에서 기독교 천사·고해소로 통일. 명조체 제목·분홍 CTA 구성.
- 배경 자산: `public/assets/kiwoom/confession-chapel.png` (글씨 없는 고해소). 마스코트: `public/assets/kiwoom/confession-angel.png` (투명 배경 천사). 염주·가부좌 등 승려 요소는 제거했다.
- `Prototype.tsx`의 `ConfessionBackdrop`, `ConfessionTitle`, `ConfessionDescription`, `ConfessionMascot`, `ConfessionGreeting`, `ConfessionTopicPicker`, `ConfessionMotto`, `ConfessionActions`로 구성을 분리했다. 모든 문구는 실제 HTML 텍스트다.
- 공통 `ConfessionReveal`이 컴포넌트 단위로 22px 상승 + 페이드인한다. 560ms duration, 0–780ms stagger. 이미지 로드 후 시작하고, 랜딩 재진입 시 재생한다. 주제 선택 시에는 다시 재생하지 않는다. `prefers-reduced-motion`에서는 즉시 표시한다.
- 고백 주제 선택 → 전체 화면 채팅 → 직접 입력 또는 추천 답변 → 원칙 제안 → 저장 완료를 시연한다.
- 예시 매매 2개 중 하나를 골라 관련 질문으로 진입할 수 있다. 매매 정보와 응답은 모두 고정 목업이다.
- 원칙 저장은 열린 랜딩의 React 상태에만 유지되며 계좌 화면으로 나가거나 새로고침하면 초기화된다. 실제 AI 호출, 서버 저장, 금융 데이터 연결은 없다.
- 제목은 로컬 패키지 Noto Serif KR 700, 본문은 Noto Sans KR. 보호된 모바일 런타임은 유지했다.
- iPhone / Pixel 화면과 기본 진입·복귀·주제 선택·예시 거래·원칙 저장 흐름 확인. 빌드 통과(번들 크기 안내 warning만 있음).

- 랜딩·대화 말투: “평안이 함께하길”, “마음을 고백하세요”를 중심으로 고백·위로·새로운 시작을 표현한다. 고어체 대신 현대 존댓말을 사용한다.

- 서비스명은 **투자 고해성사**를 유지한다. 설명은 AI 채팅을 통한 투자 회고와 개인 투자 기준 수립에 집중한다. 시작 버튼은 “나의 투자 돌아보기”, 대화 주제는 “매수 타이밍이 고민돼요” / “추가 매수 기준이 궁금해요”다.

### 전체 화면 AI 채팅

- 시작 버튼과 예시 거래에서 화면 전체를 채우는 채팅 페이지로 이동한다. 페이지는 아래에서 위로 등장한다.
- 추천 답변 3개를 입력창에 채워 보내거나, 최대 500자까지 직접 입력한다. Enter는 전송, Shift+Enter는 줄바꿈이며 한글 조합 중 Enter는 전송하지 않는다.
- 전송 후 2.4초 동안 “키움 AI가 생각하는 중”과 회전 링·점 애니메이션을 표시하고 시연용 답변을 추가한다. 전송 중 중복 요청을 막고, 화면을 나가면 타이머를 취소한다. 실제 AI 연산·통신은 없다.
- 답변 뒤에도 대화 기록과 입력창이 유지되며 후속 대화를 보낼 수 있다. 투자 원칙은 현재 랜딩 세션에 저장한다. 대화에서 나가 새로 시작하면 대화 기록은 초기화된다.
- 모바일 런타임의 KeyboardTextarea와 bottomInset을 사용해 키보드 위에 입력창을 배치한다.

- 키보드 전환 수정(2026-10-03): 키보드 탭은 입력 포커스를 유지하고, 6px 이상 움직였을 때만 드래그로 처리한다. 키보드와 입력창은 동일한 260ms CSS 전환을 사용한다. 전송 버튼은 실제 클릭까지 입력 포커스를 유지해 먼저 내려가지 않으며 Esc로도 키보드를 닫을 수 있다.

- 뒤로가기 수정(2026-10-03): 채팅 뒤의 랜딩을 유지해 복귀 시 등장 애니메이션이 재시작하지 않도록 했다. 포커스 이동으로 휴대폰 화면 전체가 밀리지 않으며, 채팅·거래 기록에서 돌아온 뒤 바로 버튼을 조작할 수 있다.
