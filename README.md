# 지산학캡스톤디자인 2026-2학기 1팀

- 키움 AI 투자 회고 모바일 웹 프로토타입 · React + TypeScript + Vite
- 요구 환경: Node.js 22, npm
- 설치: `npm ci`
- 실행: `npm run dev -- --port 4174 --strictPort`
- 로컬 접속: <http://localhost:4174/>
- 빌드: `npm run build`
- 런타임 검증: `npm run check:runtime`
- Pages 빌드: `npm run build:pages`
- 배포: `main`에 푸시하면 GitHub Actions가 자동 배포
- [공개 데모](https://kohs2k21.github.io/2026-2-1team-industry-academia-capstone-design/)
